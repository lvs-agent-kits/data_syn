最终敲定的表结构：
```text
表 1：
motifs
- motif_id
- generated_at

表 2：
tag_categories
- category_id
- category_code
- display_name
- concatenation_priority

category_code / display_name:
- scene                 / Scene
- domain                / Domain
- reference_scope       / Reference Scope
- general_document      / General Document
- format_document       / Format Document
- process_constraint_document / Process Constraint Document

表 3 
tags
- tag_id
- category_id
- tag_name
- text_content

表 4：
motif_tags
- motif_id
- tag_id
```
