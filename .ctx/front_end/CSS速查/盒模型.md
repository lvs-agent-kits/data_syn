## CSS 盒模型（Box Model）

HTML 元素的大小由 **CSS 盒模型** 决定，包含以下几个部分：

### 1. 盒模型的组成部分

```
┌─────────────────────────────────┐
│         margin (外边距)          │
│  ┌───────────────────────────┐  │
│  │      border (边框)         │  │
│  │  ┌─────────────────────┐  │  │
│  │  │   padding (内边距)   │  │  │
│  │  │  ┌───────────────┐  │  │  │
│  │  │  │               │  │  │  │
│  │  │  │   content     │  │  │  │
│  │  │  │   (内容区)     │  │  │  │
│  │  │  │               │  │  │  │
│  │  │  └───────────────┘  │  │  │
│  │  └─────────────────────┘  │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

### 2. box-sizing 属性

这是关键！`box-sizing` 决定了 `height` 和 `width` 的计算方式：

#### **content-box（默认值）**
```css
.box {
  box-sizing: content-box; /* 默认 */
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 5px solid black;
}
```

**实际大小计算：**
- **内容区宽度** = 200px（设定的 width）
- **内容区高度** = 100px（设定的 height）
- **实际总宽度** = 200 + 20×2 + 5×2 = **250px**
- **实际总高度** = 100 + 20×2 + 5×2 = **150px**

> width/height 只包含 content 区域

#### **border-box**
```css
.box {
  box-sizing: border-box;
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 5px solid black;
}
```

**实际大小计算：**
- **实际总宽度** = 200px（设定的 width）
- **实际总高度** = 100px（设定的 height）
- **内容区宽度** = 200 - 20×2 - 5×2 = **150px**
- **内容区高度** = 100 - 20×2 - 5×2 = **50px**

> width/height 包含 content + padding + border

### 3. 完整计算公式

#### content-box 模式：
```
元素实际占用宽度 = width + padding-left + padding-right + border-left + border-right
元素实际占用高度 = height + padding-top + padding-bottom + border-top + border-bottom
```

#### border-box 模式：
```
内容区宽度 = width - padding-left - padding-right - border-left - border-right
内容区高度 = height - padding-top - padding-bottom - border-top - border-bottom
元素实际占用宽度 = width
元素实际占用高度 = height
```

### 4. JavaScript 获取实际尺寸

```javascript
const element = document.querySelector('.box');

// 获取包括 padding 和 border 的尺寸（不包括 margin）
console.log(element.offsetWidth);   // 实际宽度（含 padding + border）
console.log(element.offsetHeight);  // 实际高度（含 padding + border）

// 获取精确到小数点的尺寸
const rect = element.getBoundingClientRect();
console.log(rect.width);   // 渲染后的宽度
console.log(rect.height);  // 渲染后的高度

// 通过 getComputedStyle 获取各个部分的值
const styles = window.getComputedStyle(element);
console.log(styles.width);        // CSS 设定的 width
console.log(styles.height);       // CSS 设定的 height
console.log(styles.padding);      // padding
console.log(styles.border);       // border
```
